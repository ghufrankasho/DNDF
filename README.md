🧠 Deep Neural Decision Forest (DNDF) — Binary Classification Model

A fully implemented Deep Neural Decision Forest (DNDF) built with TensorFlow/Keras for binary classification.
The model achieves 98% accuracy after tuning, training, and preprocessing.
📌 Project Overview

This project implements a DNDF (Deep Neural Decision Forest) from scratch using a custom SoftDecisionTree layer.

✔️ Features

Custom DNDF architecture (ensemble of differentiable decision trees)

Gini-based splitting

Scalable to large datasets (35k+ samples)

Includes full preprocessing pipeline

Class balancing using computed class weights

Model achieves 98% accuracy

Jupyter Notebook code included
